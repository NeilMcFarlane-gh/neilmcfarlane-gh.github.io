### QoMMMa

[QoMMMa](https://github.com/NeilMcFarlane-gh/QoMMMa) is an additive QM/MM package maintained within the Harvey group at KU Leuven. It uses Tinker for any MM-side calculations, and QM-side calculations can be performed with a variety of quantum chemistry codes including: Gaussian, ORCA, xTB, Jaguar, and Molpro. The source code is written in Fortran, and Python3 is used as a scripting language to wrap the source code and generate job files for the QM and MM packages.

### LennardJones-GSM
[LennardJones-GSM](https://github.com/NeilMcFarlane-gh/LennardJones-GSM) is a work-in-progress computational chemistry code that generates reaction pathways for rearrangements of Lennard-Jones clusters of particles using the growing string method. It is written entirely in Python3.
